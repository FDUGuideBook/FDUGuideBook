# 快速上手小清单

### 学习目标

- 理解区块链的基本原理（区块、共识、加密、智能合约）

- 会搭建基础开发环境（如 MetaMask + Remix + Ganache）

- 能独立写出简单的智能合约并部署到测试网

- 理解主流区块链应用方向（DeFi、NFT、DAO等）



### 区块链与开发环境入门

#### 学习内容

- 区块链基本概念（区块、哈希、签名、共识）

- 比特币与以太坊工作原理

- 去中心化思想 & 智能合约入门

- 环境搭建（MetaMask、Remix、Ganache）

#### 工具准备


#### 电子书

- 《精通比特币（Mastering Bitcoin）》 by Andreas Antonopoulos
  [GitHub 免费版](https://github.com/bitcoinbook/bitcoinbook)

- 《精通以太坊（Mastering Ethereum）》
  [GitHub 免费版](https://github.com/ethereumbook/ethereumbook)



### 智能合约与DApp开发

- Solidity 基础语法与安全规范

- 合约调试、部署、交互

- Web3.js / Ethers.js 连接前端与合约

- ERC-20 代币标准与NFT标准


#### 教程

- [CryptoZombies.io](https://cryptozombies.io/) — 学习Solidity的互动游戏

- [OpenZeppelin 合约文档](https://docs.openzeppelin.com/contracts) — 安全合约模板库

-   GitHub 项目：[awesome-solidity](https://github.com/bkrem/awesome-solidity)
