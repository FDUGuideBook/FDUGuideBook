# 区块链方向

身处信息技术飞速发展的时代，我们该把时间和精力投入到哪一条赛道，才能真正参与到未来的构建中？如果大家在寻找一个值得长期投入的方向，可以看看区块链。

它不只是虚拟货币，而是一种新的基础技术。区块链正在被尝试应用于解决信任成本高、数据难以流通、数字资产难以确权等现实问题，在金融、医疗、政务、文创、供应链、人工智能协作等领域都在慢慢落地。也许现在它还处在不断试错的阶段，但正因为如此，才给了我们去参与、去完善的机会。

对于学生来说，区块链是一个难得的可参与空间很大的方向：

- 不一定要成为顶级程序员才能入门，可以从简单的合约、产品设计或应用场景开始

- 可以把专业学习与真实世界的问题连接起来

- 能接触到开源社区，与世界各地的开发者合作

- 获得对未来经济与协作方式的理解

在这个方向上，我们可以慢慢探索、不断成长
