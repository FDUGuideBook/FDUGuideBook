# 一、EDA简介：什么是EDA？

**电子设计自动化**（**E**lectronic** D**esign** A**utomation，缩写：**EDA**）是指利用[计算机辅助设计](https://baike.baidu.com/item/%E8%AE%A1%E7%AE%97%E6%9C%BA%E8%BE%85%E5%8A%A9%E8%AE%BE%E8%AE%A1/1376358?fromModule=lemma_inlink)（CAD）软件，来完成[超大规模集成电路](https://baike.baidu.com/item/%E8%B6%85%E5%A4%A7%E8%A7%84%E6%A8%A1%E9%9B%86%E6%88%90%E7%94%B5%E8%B7%AF/29136?fromModule=lemma_inlink)（VLSI）芯片的[功能设计](https://baike.baidu.com/item/%E5%8A%9F%E8%83%BD%E8%AE%BE%E8%AE%A1/0?fromModule=lemma_inlink)、综合、[验证](https://baike.baidu.com/item/%E9%AA%8C%E8%AF%81/0?fromModule=lemma_inlink)、[物理设计](https://baike.baidu.com/item/%E7%89%A9%E7%90%86%E8%AE%BE%E8%AE%A1/12728832?fromModule=lemma_inlink)（包括[布局](https://baike.baidu.com/item/%E5%B8%83%E5%B1%80/0?fromModule=lemma_inlink)、[布线](https://baike.baidu.com/item/%E5%B8%83%E7%BA%BF/0?fromModule=lemma_inlink)、[版图](https://baike.baidu.com/item/%E7%89%88%E5%9B%BE/791489?fromModule=lemma_inlink)、[设计规则检查](https://baike.baidu.com/item/%E8%AE%BE%E8%AE%A1%E8%A7%84%E5%88%99%E6%A3%80%E6%9F%A5/0?fromModule=lemma_inlink)等）等流程的设计方式。（摘自[百度百科](https://baike.baidu.com/item/%E7%94%B5%E5%AD%90%E8%AE%BE%E8%AE%A1%E8%87%AA%E5%8A%A8%E5%8C%96/10508153)）



EDA是一个很大的方向，大体上可以分为前端和后端。
